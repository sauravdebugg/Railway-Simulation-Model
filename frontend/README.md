# Freight Predict Hub frontend

React 19 frontend built with Vite, Tailwind CSS, Chart.js, and Leaflet.

## Development

```bash
npm install
npm run dev
```

Set `VITE_API_URL` in `.env` when the API is hosted on a different origin. The
default is `/api`, which is used by the Vercel deployment.

## Production build

```bash
npm run build
npm run preview
```

The production output is written to `dist/`.
